# BC Labs & Consultancy

**Technology Without Boundaries.**

The official website for BC Labs & Consultancy — a full-service technology company serving organisations across Africa and internationally.

## Technology

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- Motion for React
- Three.js / React Three Fiber
- Lucide icons

## Getting started

Requirements: Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Environment

Copy `.env.example` to `.env.local` when configuring integrations. No backend credentials are required for the current frontend starter.
